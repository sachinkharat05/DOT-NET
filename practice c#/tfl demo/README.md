# TFL Demo Application

Product Inventory Management System built with C#

## Project Structure

```
catalog/
├── controllers/
│   └── ProductsController.cs
├── entities/
│   └── Product.cs
├── managers/
│   └── ProductManager.cs
├── repositories/
│   └── ProductRepository.cs
└── services/
    └── ProductService.cs

Program.cs       # Main entry point
tflassessmentDemoApp.csproj   # Project file
tflassessmentDemoApp.sln      # Solution file
```

## Features

- ✅ Product CRUD Operations
- ✅ Inventory Management
- ✅ Price Calculation with Discounts
- ✅ Stock Availability Checking
- ✅ Product Liking System
- ✅ Interactive Console Menu

## How to Run

```bash
dotnet run
```

## Usage

1. Add products to inventory
2. Update existing products
3. Remove products
4. View product details
5. Calculate discounted prices
6. Like products
